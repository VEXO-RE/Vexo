💡 TIPS DE DEPURACIÓN
════════════════════════════════════════════════════════════════════════════════

Si el buscador no funciona:
  → F12 → Console → window.DESARROLLOS
  → Debe mostrar array de desarrollos
  → Si "undefined", ejecutar actualizar_contenido.ps1

Si las imágenes no cargan:
  → Verificar que public/images/Desarrollos/ existe
  → Verificar extensiones (.webp, .jpg, .png)
  → Verificar rutas en data.js

Si el mapa se congela:
  → Abrir mapa.html directamente en navegador
  → Ver Console por errores de MapLibre

Si datos no se inyectan:
  → Ejecutar con -ValidateOnly
  → Ver si encuentra los datos
  → Si muestra 0, revisar formato de data.js
