PROBLEMAS Y SOLUCIONES
════════════════════════════════════════════════════════════════════════════════

❌ PROBLEMA: "No me deja ejecutar .ps1"
   ✅ SOLUCIÓN:
      [ ] Abre PowerShell como ADMINISTRADOR
      [ ] Ejecuta: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned
      [ ] Escribe: Y (yes)
      [ ] Intenta nuevamente

❌ PROBLEMA: "Desarrollos muestran 0"
   ✅ SOLUCIÓN:
      [ ] Ejecuta: .\actualizar_contenido.ps1 -ValidateOnly
      [ ] Verifica que dice "Encontrados: X desarrollos"
      [ ] Si muestra 0, revisar formato de src/data/data.js
      [ ] Debe tener "id: 1," (con coma)

❌ PROBLEMA: "Imágenes no cargan"
   ✅ SOLUCIÓN:
      [ ] Verifica que public/images/Desarrollos/ existe
      [ ] Verifica que hay carpetas: 1-nombre/, 2-otro/, etc.
      [ ] Verifica que imágenes tienen extensión .webp, .jpg, .png
      [ ] En data.js, ruta debe ser: VEXO_WEB/Desarrollos/1-nombre/image.webp

❌ PROBLEMA: "Buscador no funciona"
   ✅ SOLUCIÓN:
      [ ] Abre F12 → Console en navegador
      [ ] Escribe: window.DESARROLLOS
      [ ] Si muestra undefined → ejecuta actualizar_contenido.ps1 de nuevo
      [ ] Si muestra array → el buscador debería funcionar

❌ PROBLEMA: "Mapa se congela"
   ✅ SOLUCIÓN:
      [ ] Abre mapa.html directamente (sin embed)
      [ ] Si congela, revisar Console
      [ ] Verificar que MapLibre GL está cargado
      [ ] Revisar que no hay errores CORS

❌ PROBLEMA: "Git push falla"
   ✅ SOLUCIÓN:
      [ ] Verifica credenciales: git config --global user.name
      [ ] Verifica SSH: git ls-remote origin
      [ ] Si no funciona, usa: gh auth login (GitHub CLI)
      [ ] Intenta de nuevo
